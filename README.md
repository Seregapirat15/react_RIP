# React SPA — Система расчёта массы экзопланет

**Лабораторные 1–8** | Студент: Номоконов Владислав | Группа: ИУ5-53Б

## Запуск

```bash
npm install
npm run dev
```

Приложение: http://localhost:3000

## Lab 8 — Интерфейс модератора

- **Страница:** `/admin/orders` (доступна после входа как moderator/admin)
- **Short polling** — обновление списка каждые 6 сек
- **Фильтры:** статус, создатель, дата формирования
- **Кнопки:** Завершить, Отклонить, Расчёт (запуск async-сервиса)
- **Колонка «Прогресс расчёта»:** X из Y (рассчитано м-м из всего)
- **Итоговая масса** — показывается только после async-расчёта
