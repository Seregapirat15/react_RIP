# Инструкция по запуску приложения

## Быстрый старт

### 1. Запуск с mock данными (без бэкенда)

Этот режим используется для демонстрации работы фронтенда без подключения к бэкенду.

```bash
npm run dev
```

Приложение будет доступно по адресу: **http://localhost:3000**

По умолчанию настроено fallback на mock данные, если бэкенд недоступен.

### 2. Переключение режимов

#### Режим с mock данными (принудительно)

Откройте `src/services/api.ts` и измените:

```typescript
const USE_MOCK = true; // Принудительное использование mock данных
```

#### Режим с бэкендом

Откройте `src/services/api.ts` и измените:

```typescript
const USE_MOCK = false; // Попытка подключения к бэкенду
```

При этом бэкенд должен быть запущен на **http://localhost:8081**

### 3. Запуск бэкенда (если есть)

Если у вас есть бэкенд из предыдущих лаб, запустите его:

```bash
# Перейдите в директорию бэкенда
cd ../backend

# Запустите бэкенд
go run cmd/main.go
# или
python app.py
# или другая команда в зависимости от вашего бэкенда
```

Бэкенд должен работать на порту **8081**.

### 4. Проверка работы

#### Откройте браузер:
- http://localhost:3000 - Главная страница
- http://localhost:3000/services - Список услуг
- http://localhost:3000/services/1 - Детали услуги

#### Откройте DevTools (F12):
1. Перейдите на вкладку **Network**
2. Обновите страницу со списком услуг
3. Найдите запрос к `/api/services`
4. Посмотрите:
   - URL запроса
   - Параметры фильтрации (если применены)
   - Ответ сервера

## Компоненты приложения

### Навигация

1. **NavigationBar** (React-Bootstrap)
   - Логотип
   - Ссылки: Главная, Услуги
   - Адаптивная (сворачивается на мобильных)

2. **Breadcrumbs** (самописный)
   - Показывает путь: Главная / Услуги / Детали
   - Автоматически формируется из URL
   - Последний элемент - неактивная ссылка

### Страницы

1. **HomePage** - статическое содержимое
2. **ServicesListPage** - список с фильтрами
3. **ServiceDetailPage** - детальная информация

## Troubleshooting

### Проблема: Страница не открывается

```bash
# Проверьте что Vite запущен и слушает порт 3000
npm run dev
```

Должно быть: `Local: http://localhost:3000/`

### Проблема: Ошибки TypeScript

```bash
# Проверьте что установлен TypeScript
npm install
```

### Проблема: Стили не загружаются

Проверьте что в `src/App.tsx` есть импорт:
```typescript
import 'bootstrap/dist/css/bootstrap.min.css';
```

### Проблема: Изображения не отображаются

- Если с бэкендом: проверьте настройки MinIO
- Если mock: проверьте что файл `public/placeholder-service.svg` существует

### Проблема: CORS ошибка

Убедитесь что:
1. В `vite.config.ts` настроен proxy
2. Бэкенд запущен на порту 8081
3. Или используйте mock данные (USE_MOCK = true)
